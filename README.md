# Muhammad Saad · Portfolio

Personal portfolio for Muhammad Saad, Android Developer (Kotlin), built with React and Vite.

## Features

- Dark theme with warm amber accents that match the portrait
- Intro loader, staggered hero entrance and a typewriter role line
- Ember particle canvas in the hero that drifts away from the cursor
- Scroll-reveal animations (fade, slide, zoom, blur) on every section
- Material-style ripple on buttons, cards and links
- Hover effects: 3D tilt, pointer spotlight, glow borders, magnetic buttons, shine sweep on projects
- Custom cursor glow, scroll progress bar, back-to-top button with progress ring
- Scroll-spy navigation and a full-screen mobile menu
- Count-up stats and animated language bars
- Responsive from phones to wide screens; respects "reduce motion"

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files go to `dist/`. The build uses relative paths, so `dist/` can be uploaded to GitHub Pages, Netlify, Vercel or any static host.

## Edit content

All text comes from `src/data.js`. The photo is `public/saad.jpg` and the downloadable CV is `public/MuhammadSaad-CV.pdf`.
